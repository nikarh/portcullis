Changelog

Every release, newest first. Each version links to its GitHub release, which has the packages and the authors of each change. This page is generated from CHANGELOG.md when a release is made.

0.4.02026-11-07

Fixes

  • Close ways around ICC, egress and quarantine found in a bug hunt (#14) in #14
  • Stop quarantining containers for their own traffic, and fix audit suggestions (#16) in #16
  • Don't mix up a restarted or recreated container with its previous run (#17) in #17

0.3.02026-11-06

Features

  • Look the names of host: rules up again while they are in use, with a hold per container

Fixes

  • Don't recognise containers without a bridge port by their address and MAC
  • List --docker-root and --monitor-network in --help, and link the docs

Quick start

This walks through the whole cycle on one Debian or Ubuntu host: install, observe, write labels, enforce. It takes about ten minutes. On other systems, install as described in Installation and continue from step 2.

2. Let Docker’s DNS lookups be seen

Section titled “2. Let Docker’s DNS lookups be seen”

Portcullis names destinations in its reports by watching the DNS answers containers receive. It can only see them when Docker forwards lookups from the container’s address, which takes a dns setting in /etc/docker/daemon.json. Use the resolver from the host’s resolv.conf, or any other:

This is optional, but without it reports show bare addresses, and patterns in host: rules can’t work. See DNS visibility.

Section titled “6. Check it”

The second command fails with “Host is unreachable”: denied traffic is answered with an ICMP error unless deny-action = "drop". The denial shows up in portcullis watch as DENIED egress ..., and, if you configure one, runs the alert command.
